# 🌱 AI 나뭇잎 분류 & 윤리 시뮬레이터 (v4 - 학생용/관리자용 역할 분리 아키텍처)

## 1. 역할별 계정 및 화면 분리 구조 (`st.navigation`)
- **🧑‍🎓 학생용 계정 (`role = 'student'`)**:
  - `[학생 회원가입]` 또는 `[학생 로그인]`으로 접속 시 **1~4단계 학습 활동 메뉴만** 표시됩니다.
  - DB 초기화, 가짜 데이터 강제 투입, 설문 문항 수정, 다른 학생의 상세 응답 열람 기능은 노출되지 않습니다.
- **👨‍🏫 교사(관리자) 계정 (`role = 'admin'`)**:
  - 기본 관리자 계정: 아이디 **`admin`** / 초기 비밀번호 **`admin1234`** (로그인 후 `[관리자 통합 대시보드]`에서 비밀번호 변경 가능)
  - 로그인 시 **`🛠️ 관리자 통합 대시보드`**가 기본 화면으로 열리며, 공유 DB 초기화, 가짜 데이터 투입·제거, 학생 이상치 색출 로그 확인, 엑셀(`.xlsx`) 설문 문항 교체, 전체 학생 설문 결과 엑셀 내보내기, 학생 계정 비밀번호 초기화 기능을 모두 제어할 수 있습니다.
